# LABKI Links

Página de enlaces de LABKI lista para GitHub Pages.

## Publicar
Sustituye en tu repositorio `labki` los archivos `index.html` y `styles.css`, y sube también la carpeta `assets` completa. Haz Commit changes. GitHub Pages actualizará la misma URL.

## Enlaces
Instagram y TikTok están en `index.html`. Busca `instagram.com` o `tiktok.com` para cambiarlos.

## Paleta
Usa los tokens originales incluidos por LABKI: turquesa `#68C3BA`, charcoal `#2F3337`, warm white `#F7F4EE`, muted `#D8DCDA`, soft dark `#1F2326`.
