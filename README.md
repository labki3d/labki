# LABKI Link Page

Mini landing de enlaces para LABKI, pensada para móvil y GitHub Pages.

## Antes de publicar

Edita `index.html` y sustituye:
- `34600000000` por el número real de WhatsApp, con prefijo internacional y sin +.
- `hola@labki3d.com` si todavía no existe ese correo.
- `https://labki3d.com` si todavía no tenéis dominio/web.

Instagram y TikTok ya apuntan a `labki_3d`.
